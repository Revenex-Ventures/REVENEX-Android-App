# REVENEX SCHOOL ERP — USER ROLES & ACCESS CONTROL (RBAC)

## Matrix of Capabilities

| Role | Accessible Modules | Key Capabilities |
| :--- | :--- | :--- |
| **Principal / Admin** | • Executive Dashboard<br>• Student & Faculty Roster<br>• Fee Collection & Ledgers<br>• Leave Approvals<br>• Reports & Analytics<br>• Circular Publishing | • Full read/write access<br>• Approve or reject leave applications<br>• Admit students and hire faculty<br>• View institutional financial analytics |
| **Teacher / Faculty** | • Teacher Dashboard<br>• Class Attendance Register<br>• Homework Authoring<br>• Study Material Uploads<br>• Timetable & Schedule | • Mark daily roll call<br>• Create and assign homework<br>• Upload subject study resources<br>• Apply for faculty leave |
| **Student** | • Student Learning Desk<br>• Homework Tracker<br>• Term Report Cards<br>• Digital Library<br>• Class Timetable | • View daily schedule<br>• Check off completed homework<br>• Inspect grades and marks<br>• Borrow and return library books |
| **Parent / Guardian** | • Parent Portal<br>• Multi-Ward Switcher<br>• Fee Ledger & Payment<br>• Leave Application<br>• Bus GPS Tracking | • Toggle between registered children<br>• View today's attendance status<br>• Pay outstanding fees & download receipts<br>• Submit leave requests for children |
