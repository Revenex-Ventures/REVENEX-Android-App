# REVENEX SCHOOL ERP — SYSTEM OVERVIEW

## Executive Summary
**Revenex School ERP** is an enterprise-grade School Enterprise Resource Planning platform engineered for modern K-12 educational institutions. It unifies administrative operations, academic management, financial ledgers, staff workflows, and multi-channel guardian engagement into a single, high-performance Android mobile application built with Jetpack Compose, Kotlin Coroutines, and Clean Architecture.

---

## Core Philosophy
> **"One digital system for the entire school."**

Revenex eliminates disparate spreadsheets, manual paper registers, isolated notification apps, and disconnected fee collection systems by consolidating all school stakeholders into a singular unified ecosystem:
- **Principal & Executive Management**: Real-time operational intelligence, financial analytics, admissions, staff governance, and compliance.
- **Teachers & Faculty**: Smart roll-call registers, homework authoring, curriculum resources, and student progress tracking.
- **Students**: Dynamic timetables, digital homework tracker, CBSE/ICSE standard report cards, library catalogs, and study notes.
- **Parents & Guardians**: Multi-ward child switcher, live attendance monitoring, 1-tap fee payments with instant digital receipts, leave applications, and teacher communications.

## Key Technical Specifications
| Parameter | Specification |
| :--- | :--- |
| **Architecture** | Clean MVVM + Repository + Dual-Layer Data Source (Demo / Cloud) |
| **UI Framework** | 100% Jetpack Compose (Material Design 3) |
| **Language** | Kotlin 2.0+ with Coroutines & StateFlow |
| **Data Persistence** | Reactive In-Memory State Store + Cloud Firestore Mapping Layer |
| **Cloud Target** | Google Firebase (Auth, Firestore, Cloud Messaging, Storage) |
| **Security Standard** | Role-Based Access Control (RBAC), Least Privilege Authorization |
| **Target Platforms** | Android Smartphones, Foldables, and Tablets |
