# app/src/main/

Production source root for the Android app.

## Directories

- `java/com/example/` — All Kotlin source code organized into `data/`, `ui/`, and `MainActivity.kt`.
- `res/` — Android resources: drawables, mipmap launcher icons, and XML value files (strings, colors, themes).

## Key file

- `AndroidManifest.xml` — Declares the app package, permissions (INTERNET, CAMERA, READ/WRITE_EXTERNAL_STORAGE), the single `MainActivity`, and intent filters.
