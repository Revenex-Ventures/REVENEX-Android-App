# app/src/

Source root for the Android app module.

## Directories

- `main/` — Production source code: Kotlin files, AndroidManifest.xml, and resources (drawables, icons, values).
- `androidTest/` — Instrumented tests that run on a real device or emulator (requires a connected Android device).
- `test/` — JVM unit tests and Roborazzi screenshot tests. Run with `.\gradlew.bat test`.
